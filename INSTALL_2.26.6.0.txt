VADAFOK Studio 2.26.6.0 - Smart Caption Performance Overlay

Installation
1. VADAFOK Studio beenden.
2. Den Inhalt dieses Overlay-Ordners über den bestehenden Projektordner kopieren.
3. Vorhandene Dateien ersetzen.
4. Lokal ausführen:
   python -m compileall vadafok_studio tests
   python -m unittest discover -s tests -v
5. Anwendung starten und mindestens fünf Smart-PNG SHOW-Vorgänge ausführen.
6. Danach logs/sync_profile.log bereitstellen.

Änderungen
- Font-Cache nach Fontdatei und Größe.
- Banner-Cache mit automatischer Invalidierung bei Dateiänderung.
- Detaillierte Zeitmarken für Banner-Laden, Canvas, Font-Fit, Textzeichnen und PNG-Speichern.
- Render-Metadaten: Textlänge, Bildgröße, Zeilen, Fontgröße, Fit-Versuche, PNG-Dateigröße.
- Version 2.26.6.0.
