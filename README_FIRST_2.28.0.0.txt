VADAFOK Studio 2.28.0.0
========================

LIVE CARD TRANSLATION
---------------------
- Say Live Card. The existing Live Card page opens; no extra window opens.
- Whisper places the spoken text directly into the normal Message field.
- An English preview is prepared below the Message field.
- The spoken/original text remains active by default.
- Say VADAFOK ENGLISH only when you want to replace the active text with the translation.
- Say VADAFOK SHOW to send the currently active Message text to OBS.
- Optional: VADAFOK TEXT restores the original dictated text.

INSTALLATION
------------
1. Close VADAFOK Studio.
2. Extract this ZIP into the VADAFOK Studio project folder.
3. Replace existing files.
4. Start VADAFOK Studio normally.

TEST
----
1. Say: Live Card
2. Say: Das war knapp.
3. Confirm the Message field contains: Das war knapp.
4. Confirm ENGLISH PREVIEW shows: That was close.
5. Say: VADAFOK ENGLISH
6. Confirm the Message field now contains: That was close.
7. Say: VADAFOK SHOW
