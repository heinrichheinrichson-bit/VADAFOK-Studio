VADAFOK Studio 2.28.0.2 — F8 Live Card correction

INSTALLATION
1. VADAFOK Studio completely close.
2. Extract this ZIP into the VADAFOK Studio project folder.
3. Replace existing files.
4. Start VADAFOK Studio.

TEST
1. Say: Live Card
2. Dictate a German sentence.
3. The sentence must appear in the F8 textbox.
4. The English translation must appear inside the same F8 window.
5. Say: VADAFOK RESET — textbox and translation reset.
6. Dictate again, then say: VADAFOK SHOW — sends to OBS and closes F8.
7. Open again and say: VADAFOK STOP — closes F8 without sending.
