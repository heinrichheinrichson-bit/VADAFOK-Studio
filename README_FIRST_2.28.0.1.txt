VADAFOK Studio 2.28.0.1 — F8 Live Card Translation Fix
========================================================

Diese ZIP ist ein Overlay für deine bereits installierte Version 2.28.0.0.

INSTALLATION
1. VADAFOK Studio vollständig schließen.
2. Den Inhalt dieser ZIP in den VADAFOK-Studio-Projektordner kopieren.
3. Vorhandene Dateien ersetzen lassen.
4. VADAFOK Studio starten.

TEST
1. Sage: Live Card
2. Das kleine F8-/Quick-Caption-Fenster muss sich öffnen.
3. Diktiere einen deutschen Satz.
4. Der deutsche Satz steht sofort im vorhandenen Textfeld.
5. Die englische Vorschau erscheint im selben kleinen Fenster.
6. Sage: VADAFOK ENGLISH
7. Das vorhandene Textfeld enthält jetzt die englische Übersetzung.
8. Sage: VADAFOK SHOW

WICHTIG
Das große Live-Card-Modul wird durch den Sprachbefehl nicht mehr geöffnet.
Quick Cards bleiben unverändert.
