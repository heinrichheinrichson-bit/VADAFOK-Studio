VADAFOK Studio 2.28.0.0
========================

Added
-----
- Integrated English translation preview directly into the existing Live Card page.
- Added asynchronous Live Card translation using the shared DeepL runtime.
- Added VADAFOK ENGLISH selection for Live Card.
- Added optional VADAFOK TEXT restoration of the original dictated text.

Changed
-------
- The Live Card wake phrase now opens the actual Live Card page instead of Quick Caption.
- Whisper dictation writes directly into the normal Live Card Message field.
- VADAFOK SHOW uses the existing Live Card SHOW/OBS path while Live Card mode is active.

Unchanged
---------
- Quick Cards retain their suggestion window and existing selection workflow.
- Original dictated Live Card text remains active unless VADAFOK ENGLISH is spoken.
