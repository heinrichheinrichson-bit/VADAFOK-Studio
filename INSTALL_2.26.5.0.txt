VADAFOK Studio 2.26.5.0 – Synchronization Profiler

Basis:
- Installation 2.26.4.1

Installation:
1. VADAFOK Studio schließen.
2. ZIP im Projektstamm entpacken und vorhandene Dateien überschreiben.
3. Tests ausführen:
   python -m compileall vadafok_studio tests
   python -m unittest discover -s tests -v
4. VADAFOK starten, OBS verbinden und mindestens fünf Live-Card-SHOWs auslösen.
5. Danach diese Datei öffnen bzw. zur Analyse bereitstellen:
   logs/sync_profile.log

Hinweise:
- Der Profiler ist in diesem Diagnose-Sprint standardmäßig aktiviert.
- Er misst Python-/WebSocket-Aufrufzeiten. "Banner group enable request finished"
  bedeutet, dass OBS den Request bestätigt hat; es ist keine Messung des tatsächlich
  gerenderten Videoframes.
- Zum Abschalten in data/config.json setzen:
  "sync_profiler_enabled": false

ROLLBACK:
Bei fehlgeschlagenen Tests oder Runtime-Problemen die gesicherten Dateien aus
2.26.4.1 wiederherstellen.
