# VADAFOK Studio 2.24.4.1 – Visual Library Picker – One-Click Apply

Nur wenn die Library über `SET BACKGROUND FROM LIBRARY` geöffnet wurde:

1. Bild anklicken;
2. Bild wird sofort als Template-Hintergrund übernommen;
3. automatische Rückkehr zum Template Editor.

`SHOW / USE` ist in diesem Picker-Modus nicht mehr nötig.

Beim normalen Öffnen der Library bleibt das bisherige Auswahlverhalten
vollständig erhalten.
