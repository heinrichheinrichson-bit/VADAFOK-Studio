# Development Rules

1. Read `00_PROJECT_VISION.md` before changing code.
2. One main feature per version.
3. Do not redesign stable modules without a proven need.
4. Build on the latest stable version only.
5. Test before GitHub save.
6. Documentation is cumulative: never erase historical ideas.
7. VADAFOK must remain usable without AI, voice control or cloud services.
8. Voice control must be optional and must never send microphone audio to OBS.
