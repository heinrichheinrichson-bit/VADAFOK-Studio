# VADAFOK Studio 2.25.1.0a

## RefreshManager Compatibility

This corrective overlay keeps `TemplateRefreshManager` as a non-invasive
foundation while restoring the exact legacy refresh paths used by selection
changes and template switching.

No user-facing behavior is intentionally changed. Existing partial-refresh,
incremental-properties, zoom, drag, selection, and history behavior remains the
source of truth.
