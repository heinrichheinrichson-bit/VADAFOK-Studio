# VADAFOK Studio 2.24.3 – Template Editor – Partial Selection Refresh

Beim Wechsel eines Templates wird der Template Editor nicht mehr vollständig
neu aufgebaut.

Gezielt aktualisiert werden:

- Auswahlmarkierung in der Template-Liste;
- Status mit dem Template-Namen;
- Properties;
- Canvas;
- Layers;
- Style Presets.

Unverändert bleiben:

- komplette Seitenstruktur;
- Toolbar und Steuerelemente;
- Zoom;
- Pan-Einstellungen;
- Smart-Guide-Einstellungen.

Das Lag beim Ziehen wird bewusst erst im nächsten Performance-Schritt behandelt.
