# VADAFOK Studio 2.24.4 – Visual Library Background Picker

Der Button `SET BACKGROUND FROM LIBRARY` öffnet direkt die vorhandene Library
im Ordner `Templates`.

Die vorhandene visuelle Oberfläche wird vollständig wiederverwendet:

- Thumbnail-Raster;
- Dateiname und Tags;
- große Auswahlvorschau;
- Suche und Favoritenfilter.

`SHOW / USE` oder ein Doppelklick übernimmt das ausgewählte Bild als
Template-Hintergrund und kehrt automatisch zum Template Editor zurück.

Der normale Library-Betrieb außerhalb dieses Picker-Modus bleibt unverändert.
