## Text Engine Future

### Curved Text
Texte sollen entlang einer Kurve verlaufen können.

Beispiele:
- Kreisbogen
- Halbkreis
- freie Kurve
- oberer Bogen
- unterer Bogen

Anwendungsfälle:
- Banner
- Logos
- Embleme
- Vereinswappen
- Turniergrafiken
- Social-Media-Designs

Mögliche spätere Optionen:
- Bogenradius
- Innen / Außen
- Buchstabenabstand entlang der Kurve
- Text spiegeln
- Startwinkel
- Endwinkel
- Text auf Pfad
