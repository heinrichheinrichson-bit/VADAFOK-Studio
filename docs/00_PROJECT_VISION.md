# VADAFOK Studio — Project Vision

VADAFOK Studio is a production and direction tool for a silent live stream inspired by classic silent movies.

The streamer does not speak on stream. Communication happens through Live Cards, Quick Cards, banners, intertitles, scene cards, music, timing and visual direction.

Voice control is allowed only as a private control interface. Voice audio is never sent to OBS by VADAFOK Studio.

AI may later assist with shortening, translating or restyling intertitle text, but the program must remain fully usable offline and without AI.

Every new feature must answer:

> Does this make the silent-movie live stream easier, faster or more atmospheric?
