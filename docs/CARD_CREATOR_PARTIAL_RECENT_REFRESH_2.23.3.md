# VADAFOK Studio 2.23.3 – Card Creator – Partial Recent Refresh

Beim Entfernen eines Recent-Eintrags wird nicht mehr die komplette
Card-Creator-Seite neu aufgebaut.

Stattdessen wird ausschließlich der dedizierte Recent-Templates-Container
aktualisiert.

Dadurch bleiben erhalten:

- Vorschau;
- aktuelle Template-Auswahl;
- Eingaben;
- Display-Duration;
- OBS-Status;
- Scrollposition der übrigen Bereiche.
