# Code Style

## Allgemein
- Lesbare Funktionsnamen
- Kleine Funktionen mit klarer Aufgabe
- Kommentare nur bei komplexer Logik

## Python
- snake_case für Funktionen und Variablen
- Klassen in PascalCase
- Konstante Werte in GROSSBUCHSTABEN

## UI
- Einheitliche Farben
- Wiederverwendbare Komponenten bevorzugen
- Keine Magic Numbers ohne Erklärung
