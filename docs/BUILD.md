## Release-Ablauf

1. Version erhöhen
2. ZIP erstellen
3. Tests durchführen
4. Dokumentation aktualisieren
5. Git Commit
6. Git Push
7. GitHub Project aktualisieren

## Commit-Beispiel

git add .
git commit -m "vX.Y.Z - Beschreibung"
git push

## Ziel

Jeder Commit auf main ist stabil und nachvollziehbar.
