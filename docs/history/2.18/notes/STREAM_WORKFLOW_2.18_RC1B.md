# VADAFOK Studio 2.18 RC1B – Stream Workflow Final Polish

RC1B korrigiert ausschließlich die Semantik von **Vadafok Stop**.

- **X / Escape:** Fenster schließen, Entwurf behalten.
- **Show:** Nach erfolgreicher Ausgabe Entwurf löschen.
- **Reset:** Text und Entwurf löschen.
- **Vadafok Stop / STOP-Schaltfläche:** Vorgang vollständig abbrechen, Entwurf löschen.

Die Korrektur gilt auch, wenn das Voice-Quick-Card-Vorschlagsfenster geöffnet ist.
Bestehende Dokumentation wird durch diese Datei nicht überschrieben.
