# Contributing

## Ziel
Diese Richtlinien sorgen dafür, dass VADAFOK Studio konsistent weiterentwickelt wird.

## Workflow
1. Feature entwickeln
2. Tests durchführen
3. Dokumentation aktualisieren
4. Git Commit
5. Git Push

## Regeln
- Kleine, nachvollziehbare Commits
- Keine unfertigen Features auf main
- Jede stabile Version erhält CHANGELOG und ROADMAP Update
