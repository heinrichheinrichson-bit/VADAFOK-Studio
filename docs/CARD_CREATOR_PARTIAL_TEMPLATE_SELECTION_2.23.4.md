# VADAFOK Studio 2.23.4 – Partial Template Selection Refresh

Beim Anklicken eines Templates wird die Card-Creator-Seite nicht mehr komplett
neu aufgebaut.

Gezielt aktualisiert werden:

- Recent-Templates-Markierung und Reihenfolge;
- Auswahlmarkierung unter ALL TEMPLATES;
- Card-Data-Formular;
- Vorschau.

Unverändert bestehen bleiben:

- Display Duration;
- OBS-Status;
- SHOW/HIDE-Bereich;
- übrige Card-Creator-Struktur;
- Scrollposition der Seite.
