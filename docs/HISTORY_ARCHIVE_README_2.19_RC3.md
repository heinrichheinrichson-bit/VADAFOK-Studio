# VADAFOK Studio – Dokumentationsarchiv

Dieser Ordner bewahrt historische Installationsanleitungen, RC-Notizen,
Release-Dokumente und Entwicklungsanhänge auf.

## Regeln

- Inhalte werden archiviert, nicht gelöscht.
- Aktive Dokumente wie `ROADMAP.md`, `docs/IDEAS.md`,
  `docs/MASTER_ROADMAP.md`, `docs/CHANGELOG.md` und
  `docs/Voice_Control.md` bleiben außerhalb des Archivs.
- Die ursprünglichen Dateinamen bleiben erhalten.
- Jede automatisierte Archivierung erzeugt Manifest und Logdatei.
- Ein Rollback-Skript kann die Verschiebungen rückgängig machen.
