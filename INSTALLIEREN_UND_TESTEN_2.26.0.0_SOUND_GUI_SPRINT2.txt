VADAFOK Studio 2.26.0.0 - Sound Effects Sprint 2

BASIS
- Installierter und erfolgreich getesteter Sprint 1 SoundService
- Git-Basis davor: 81ccba2ede1143e79007062dc1223df0185db8b1

INSTALLATION
1. Anwendung schließen.
2. ZIP im Hauptordner des VADAFOK-Studio-Repositories entpacken.
3. Vorhandene Dateien überschreiben.

TEST
Git Bash:
  python -m compileall -q vadafok_studio tests
  python -m unittest discover -s tests -p "test_*.py"

Oder unter Windows:
  RUN_2.26.0.0_SOUND_GUI_SPRINT2_TESTS.bat

MANUELLER TEST
1. Anwendung starten und Live Card öffnen.
2. STREAM EFFECT muss sichtbar sein.
3. CHANGE EFFECT anklicken und eine WAV unter <Projekt>/Sounds wählen.
4. Der Dateiname muss als aktueller Effekt erscheinen.
5. PREVIEW muss die WAV abspielen.
6. Anwendung neu starten: Auswahl muss erhalten bleiben.
7. SHOW testen: In Sprint 2 darf SHOW noch keinen Sound automatisch auslösen.
