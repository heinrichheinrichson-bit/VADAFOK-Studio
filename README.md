# VADAFOK Studio 2.8.3

## Neu

Export Profiles im Card Creator.

Profile:
- Broadcast PNG
- OBS Overlay PNG
- YouTube Thumbnail JPG
- Instagram Square PNG
- TikTok Vertical PNG

## Wichtig

Export Profiles ändern:
- Dateiformat
- Dateiname
- Zielgröße

## Installation

Direkt über v2.8.2 installieren:

1. VADAFOK Studio schließen.
2. ZIP entpacken.
3. Inhalt in Projektordner kopieren und überschreiben.
4. Mit `Start VADAFOK Studio.bat` starten.
