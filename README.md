
# VADAFOK Studio 0.2

## Start

```bat
py -m pip install -r requirements.txt
py run.py
```

## Projektordner

In Settings den Ordner wählen, z.B.:

```text
F:\Bilder\Vadafok\Stream
```

Studio sucht in:

- Library
- Live Cards
- Scene Cards
- Banners
- Templates
- Fonts
- Sounds
- Projects

## Neu in 0.2

- Thumbnail-Galerie

- neue empfohlene Ordnerstruktur
- OBS-Steuerung bleibt erhalten
