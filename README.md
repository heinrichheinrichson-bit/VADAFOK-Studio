## Test

1. Banner Editor öffnen.
2. Banner auswählen.
3. Font Size ändern.
4. Textfarbe ändern, z.B. `#FFD36A`.
5. Stroke Width ändern.
6. SAVE PROFILE.
7. Live Card öffnen.
8. Diesen Banner verwenden.
9. Engine `smart_png`.
10. SHOW drücken.
11. Prüfen, ob OBS die Profilwerte nutzt.
